SMP AL-IMAM ISLAMIC SCHOOL • TP 2026/2027

SEKOLAH MENENGAH PERTAMA AL-IMAM ISLAMIC SCHOOL

Sistem penilaian rapor kinerja holistik murid di bawah naungan Al-Imam Islamic School. Kelola data siswa (159 santri, 7 kelas), input nilai akhir UTS (STS), capaian kompetensi, diniyah & kepribadian, serta dapatkan cetakan rapor standar secara otomatis.

Panduan Langkah Penggunaan Aplikasi

1 LANGKAH AWAL

Inisialisasi Database

Jalankan "Inisialisasi Database Rapor" di Google Sheets untuk membuat & mengisi data default.

2 MASTER DATA

Kelola Data Siswa

Masuk ke menu Data Siswa untuk menambah identitas manual atau Bulk Import CSV/Excel.

3 PENILAIAN

Input Nilai & Capaian

Klik menu "Nilai Akademik" untuk input skor akhir UTS (0-100) dan catatan kualitatif.

4 LAPORAN

Cetak & Unduh PDF

Klik "Cetak Rapor" atau Buku Leger lalu tekan tombol cetak untuk lembar fisik rapor.

5 ADMIN

Kustomisasi CMS

Masuk ke Pengaturan & CMS (sandi: admin123) untuk kustom profil & rubrik.
