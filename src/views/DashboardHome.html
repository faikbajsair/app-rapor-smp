Sistem penilaian rapor kinerja santri di bawah naungan Yayasan / Sekolah SMP Al-Imam. Kelola data siswa, input nilai akhir UTS (0-100), pantau buku leger 16 mapel, serta dapatkan cetakan lembar rapor resmi secara otomatis.

1 Langkah Awal

Inisialisasi Database

Hubungkan database Sheets / Cloud untuk memuat data master & indikator default.

2 Master Data

Kelola Data Siswa

Masuk ke menu Data Siswa untuk menambah identitas manual atau Bulk Import CSV.

3 Penilaian

Input Nilai Akhir UTS

Klik tombol "Nilai" di daftar mapel untuk menginput skor UTS & catatan kualitatif.

4 Laporan

Cetak & Unduh PDF

Klik "Lihat Rapor" lalu tekan tombol "Cetak / Simpan PDF" untuk lembar cetak fisik.

5 Admin

Kustomisasi CMS

Masuk ke Pengaturan & CMS untuk kustom identitas yayasan, kepsek & rubrik.
