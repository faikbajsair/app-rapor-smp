Dukungan Vercel Proxy Serverless (Anti-CORS)

Aplikasi ini dilengkapi Vercel Serverless Proxy (/api/gas) yang otomatis meneruskan request ke Apps Script tanpa hambatan browser CORS policy. Data tersinkronisasi dua arah ke Google Sheets database.

Panduan Deploy Apps Script

1

Buka script di Google Apps Script Editor.

2

Klik tombol Deploy > Manage deployments (atau New deployment).

3

Pastikan opsi berikut:

  • Execute as: Me (Akun Anda)
  • Who has access: Anyone (Siapa saja)
4

Salin URL Web App publik yang dihasilkan (format: https://script.google.com/macros/s/.../exec) dan tempel pada input di samping.
